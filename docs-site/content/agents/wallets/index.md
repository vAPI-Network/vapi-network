- [How wallets work](/agents/wallets/how-wallets-work/) — A device vault holds separate local accounts with their own USDC balances, payment caps, and balance ceilings.
- [Limits and ceilings](/agents/wallets/limits-and-ceilings/) — Account caps, balance ceilings, Router allowances, and local run guards bound an agent's spending and execution.
- [Sending and distributing](/agents/wallets/sending-and-distributing/) — The vapi client sends USDC once or distributes it across local accounts while signing keys stay on the device.
- [Backup and recovery](/agents/wallets/backup-and-recovery/) — A recovery phrase and owner-encrypted cloud backup let you restore a local vault without sending plaintext keys to vAPI Network.
- [Troubleshooting](/agents/wallets/troubleshooting/) — Fix Linux keyring setup errors, configure headless vault storage, and recover older Windows vaults.
