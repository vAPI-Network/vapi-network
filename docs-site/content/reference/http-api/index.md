- [HTTP API overview](/reference/http-api/api-overview/) — The vAPI Network HTTP API provides public Call discovery reads and bearer-authenticated listing management.
- [Discovery and services](/reference/http-api/discovery-and-services/) — Call discovery endpoints filter API listings by capability, kind, network, or category and rank results by group and relevance.
- [Listing detail](/reference/http-api/listing-detail/) — Call listing endpoints expose published catalog rows, individual listing details, and a public liveness recheck.
- [Stats and activity](/reference/http-api/stats-and-activity/) — Beta stats and activity endpoints report onchain-observed x402 settlements and catalog counts rather than vAPI Network revenue.
- [Burn and supply](/reference/http-api/burns/) — Public token supply, buyback totals and the paginated vAPI burn ledger.
- [Feed and API catalog](/reference/http-api/feed-and-api-catalog/) — Call exposes an Atom feed for new verified listings and an RFC 9727 API catalog for machine-readable discovery.
- [Listings write API](/reference/http-api/listings-write-api/) — The Call write API uses bearer authentication to publish, activate, update, and manage provider listings.
- [Claim and edit](/reference/http-api/claim-and-edit/) — The Call claim API requires bearer authentication and a payout-wallet signature before a provider can edit a mirrored listing.
- [Agents and Router](/reference/http-api/agents-and-router/) — HTTP routes for owner links, controls, prepaid balances, and live Router keys and usage.
- [Router deposit contracts](/reference/http-api/router-deposit-contracts/) — Base mainnet deployment addresses and USDC forwarding for Router deposits.
