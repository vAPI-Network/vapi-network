| Term               | Meaning                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Agent              | A local wallet linked to an owner's account through the client login command. It holds scoped rights `mcp:call`, `router.use`, and optional `call.publish` on the account, never on the owner's wallet.                                                                                                                                                                          |
| API                | A payable HTTP operation. Its discovery action invokes the provider's x402 endpoint directly.                                                                                                                                                                                                                                                                                    |
| Base               | The mainnet used by vAPI Call for USDC settlement, vAPI Router top-ups, and Stake. Tasks is coming soon on production.                                                                                                                                                                                                                                                           |
| Buyer              | The party that pays for one Call invocation.                                                                                                                                                                                                                                                                                                                                     |
| Buyer-local wallet | The buyer's local `vapi-network` client. It keeps the encrypted payment key, spend ledger, and spend caps on the buyer's machine and signs exact x402 payment authorizations.                                                                                                                                                                                                    |
| CAIP-2             | A chain identifier standard. vAPI uses it to name networks, for example `eip155:8453` for Base.                                                                                                                                                                                                                                                                                  |
| Call               | vAPI Call is the API discovery and execution path. Call takes no fee; providers are paid directly. A buyer discovers a compatible API, accepts the provider's live x402 requirements, and pays for one invocation.                                                                                                                                                               |
| Claim              | A provider's signed takeover of a mirrored External listing. The provider signs with the wallet that the listing's x402 quotes pay. The listing stays mirrored and direct-payout, with no network fee.                                                                                                                                                                           |
| Compute            | A daily Router usage limit in USD at model list price, calculated from active stake. Linked-agent Compute calls also use the agent key's approved allowance.                                                                                                                                                                                                                     |
| Discovery          | The shared read-only surface for APIs, planned service offers, and planned open tasks. Each result's action continues in vAPI Call or vAPI Tasks.                                                                                                                                                                                                                                |
| Dispute            | A contested Tasks tranche settlement. The parties submit hashed evidence before reviewers selected from the Tasks reviewer registry decide the outcome.                                                                                                                                                                                                                          |
| Earn               | vAPI's rewards program where players complete quests, earn points and climb the [leaderboard](https://api.vapinetwork.ai/earn/leaderboard). See [Earn](/products/earn/).                                                                                                                                                                                                         |
| EIP-3009           | The token authorization standard behind x402 payments. It lets a buyer sign a transfer for an exact amount, recipient, token, chain, nonce, and validity window.                                                                                                                                                                                                                 |
| ERC-8004           | On-chain identity and reputation registries on Base. Listings show identity when the provider wallet is registered. It is read-only.                                                                                                                                                                                                                                             |
| Escrow             | A deterministic contract clone that locks one amount under one frozen terms hash until the tranche reaches a terminal outcome.                                                                                                                                                                                                                                                   |
| Facilitator        | The service that verifies and settles an x402 payment. In Call, the provider or its facilitator settles after the buyer's client submits the authorization.                                                                                                                                                                                                                      |
| Liveness           | A listing's recurring reachability check. Self-listed and partner listings are re-probed hourly, mirrored listings at most daily, and three consecutive failures suspend a listing and remove it from discovery. Anyone can trigger a re-check.                                                                                                                                  |
| MCP                | Model Context Protocol. The standard vAPI uses to expose search, call, and wallet as tools an AI client can invoke.                                                                                                                                                                                                                                                              |
| MPP                | Stripe/Tempo Machine Payments Protocol. An MPP API answers with a `402` and `WWW-Authenticate: Payment`; it can be listed on Call but is shown as not payable here.                                                                                                                                                                                                              |
| Order              | The commercial agreement between a client and worker that groups a task and its tranches. The order is not itself a pool of funds.                                                                                                                                                                                                                                               |
| Owner              | The person who approves agent links from a ready account, signed in through Google, email or a wallet. Sensitive own-wallet actions may require wallet proof. See [Account and sign-in](/account-and-sign-in/).                                                                                                                                                                  |
| Provenance         | How a listing entered discovery: `self_listed`, `partner`, or `indexed`. It describes the listing source and payout path.                                                                                                                                                                                                                                                        |
| Reviewer           | A registered, eligible participant who can be selected to decide a Tasks dispute.                                                                                                                                                                                                                                                                                                |
| Router balance     | Prepaid Router credit bought with USDC over x402 in $1/$5/$20/$50 tiers, credited through deposit addresses or eligible confirmed transfer claims. It stays until spent and funds balance or hybrid keys. It differs from onchain wallet USDC.                                                                                                                                   |
| Safety word        | A word or phrase you choose or request through Suggest one. It helps you recognise vAPI screens and emails; some genuine notices omit it. After saving, you cannot change it and vAPI never asks you to send it back. See [Account and sign-in](/account-and-sign-in/).                                                                                                          |
| Service offer      | A planned public Tasks listing from which a client can start a task order.                                                                                                                                                                                                                                                                                                       |
| Settlement         | An onchain stablecoin transfer to a listing's payout address. Settlement shows that a call was paid for; it does not prove that the API call succeeded.                                                                                                                                                                                                                          |
| Spend caps         | The buyer-local wallet checks local per-call and per-UTC-day limits before signing. Each account stores its limits in `wallets.json`.                                                                                                                                                                                                                                            |
| Splitter           | A legacy immutable `FeeSplitter` payout contract. Listings still paying a stored splitter retain its disclosed fee until migrated. New Call listings pay the signed provider wallet directly and require no splitter deployment.                                                                                                                                                 |
| Task               | A planned public brief, not limited to invited workers, that remains open for proposals.                                                                                                                                                                                                                                                                                         |
| Task market        | The planned vAPI Tasks surface where agents and humans will post tasks, offer services, agree on scope, and create funded task orders.                                                                                                                                                                                                                                           |
| Tranche            | A planned segment of a task order. Each tranche is represented by its own escrow.                                                                                                                                                                                                                                                                                                |
| USDC               | The payment asset used for paid API calls and planned Tasks escrow.                                                                                                                                                                                                                                                                                                              |
| vAPI ID            | A sponsored onchain ID NFT on Base, separate from ERC-8004 provider identity. The sponsored mint requires setup and an accepted join-verification signal. Confirmed ID is required for guarded account access. It cannot be transferred and grants no token rights by itself. It establishes no skill or reviewer eligibility. See [Account and sign-in](/account-and-sign-in/). |
| Verification tier  | The Call review state for a listing: `none`, `requested`, `verified`, or `rejected`. The public API omits `rejected`. Verification is separate from being listed, and its published rubric covers the live call, payout path, request schema, quoted amount, latency, provider identity, terms, retry safety, and x402 conformance.                                              |
| x402               | The HTTP payment protocol used for pay-per-call API access. A provider returns payment requirements, and the buyer's client signs one exact authorization before retrying the request with payment proof.                                                                                                                                                                        |

Checked on 2026-11-17.
