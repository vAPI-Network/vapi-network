# `@vapi-network/mcp`

The stdio MCP server behind `vapi mcp`: namespaced tools that let an agent
search and read the public vAPI documentation, search the vAPI catalogue, read a listing's request contract, pay an x402 API
from a local wallet, read paid origins during an agent run, and read balances, receipts and the status screen
(`vapi.status`, `vapi.accounts`, `vapi.siblings`). It can derive an account and lower its caps,
but it never renames, removes, backs up or exports one, and no tool returns a
recovery phrase, private key or passphrase.

`docs.search` and `docs.read` are read-only and work without an account, vault
or payment. Returned documentation text is reference material, not instructions.

One entry point, `@vapi-network/mcp`, exporting `createVapiServer`,
`startStdioServer`, `loadServerConfig`, `WalletSession` and the individual
`callService`, `inspectService`, `searchMarketplace` and `getWallet` tools.

See the [root README](https://github.com/vAPI-Network/vapi-network/blob/main/docs/mcp.md) for the editor configuration, the full tool table and the deprecated aliases.

`call.read` is available to agent runs with the `read` grant. It only sends
GET requests to HTTPS origins that the same agent paid in the current run,
follows guarded redirects, and never makes another payment. A 402 may be
retried once with a SIWX sign-in proof bound to that origin. The MCP surface
lists the tool for schema alignment, but calls outside an agent run are refused.
