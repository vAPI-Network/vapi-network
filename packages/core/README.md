# `@vapi-network/core`

The non-custodial heart of [vAPI Network](https://github.com/vAPI-Network/vapi-network):
the x402 protocol, the wallet store, spend policy, the network guard, discovery
merge, public documentation access and the append-only receipt ledger. Keys stay on the caller's machine.
This package proxies no payment and sends no telemetry.

Seven entry points: `@vapi-network/core`, `@vapi-network/core/secrets`, `@vapi-network/core/backup`, `@vapi-network/core/cloud-backup`, `@vapi-network/core/api-key`, `@vapi-network/core/agent-link` and `@vapi-network/core/router-client`.

- `@vapi-network/core`, everything an agent-driven surface may use: accounts,
  balances, `WalletStore`, `SpendPolicy`, `resolvePassphrase`, receipts, stats
  and the x402 primitives.
- `@vapi-network/core/secrets`, human-only. `exportRecoveryPhrase`,
  `exportKeystoreKeys`, `createKeystoreWithPhrase` and `decryptPrivateKey`
  return a recovery phrase or a private key, so they are deliberately not
  re-exported from the main index and the MCP package is forbidden to import
  them.
- `@vapi-network/core/backup` creates, opens, exports and restores encrypted vault backups, derives owner keys, and seals relay payloads. The MCP package is forbidden to import it.
- `@vapi-network/core/cloud-backup` runs owner relays, stores per-device backup keys, uploads envelopes and restores owner-approved backups. The MCP package is forbidden to import it.
- The `@vapi-network/core/api-key` entry point stores and resolves the registry API key without placing it in parsed MCP configuration.
- The `@vapi-network/core/agent-link` entry point handles device linking and agent tokens for a wallet.
- The `@vapi-network/core/router-client` entry point lists router models, reads usage and buys router balance.
