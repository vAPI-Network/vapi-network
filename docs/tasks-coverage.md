# Tasks V2 action coverage

This table compares the hosted Tasks actions with this client's CLI, SDK and local MCP.
Tasks V2 is live on Base mainnet; local signing uses the verified deployment pins.
Coverage describes reachable actions, rather than identical argument names or every optional hosted field.

CLI entries below follow the task command prefix. MCP entries follow the Tasks namespace.
SDK entries refer to exports from `@vapi-network/core/tasks`, also exported as `tasks` by `vapi-network`.
The hosted canonical read/post adapter is `createHostedTasksClient` from `@vapi-network/mcp`.

Two small aliases now route hosted action names to the existing verified executor.
Closing through milestone and nonce revocation through sign retain the dedicated verbs.
The bundled SDK also exports the existing Tasks API through its `tasks` namespace.

The remaining gaps require new core contracts or verification paths, rather than interface wiring.
Reviewer administration needs a deployment-scoped operation journal and resolver/registry plan validation.
Bounty commitments need proposal-bound hashes, deadline checks and transaction recovery.
Pool admission and membership need authenticated schemas and signed claim handling.
Hosted dry-run previews and raw hosted signing-intent handover are also outside the local API.
