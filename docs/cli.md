# CLI reference

Every `vapi` command, its options and its exit codes. Install the CLI with `npm i -g vapi-network`, or prefix a command with `npx vapi-network`.

The code installer and Claude Code/Codex launchers below are available since 0.12.0. Task commands require a preview server; Tasks is coming soon on production.

Most commands accept `--json` and write one success or error value to stdout.
The Claude Code and Codex launchers are interactive and reject that flag.
Task watch and a partially completed scope-signing flow can emit newline-delimited
JSON; delivery emits one result after chain success. See [Task commands](./tasks.md#cli). Exit codes are
`0` for success, `1` for an operational failure, and `2` for invalid usage or
an announced preview-only command.
Solana listings remain searchable. Inspecting or paying one returns
`unsupported_network` (CLI exit `1`); vault payments on Solana arrive in a later release.
Inspect shows the registry’s last observed quote; pay fetches a fresh quote before signing.
Hosted search hides listings in outage unless `--include-outage` is set.
API hits can include health and cheaper or healthier alternatives; inspect can
include response schemas and an example request. Search, inspect and pay JSON
results include zero to four next-action hints.

Protected-vault access and legacy secret-store commands are documented in the [wallet guide](./wallets.md).

Every wallet command takes `--account <name>`, falls back to `VAPI_WALLET`, then the default from `vapi accounts use`; `--wallet <name>` is deprecated and still accepted.

Task exit codes are `0` ok, `1` error or invalid usage, `2` policy refusal, and `3` approval needed in non-interactive mode. Scope signing requires `--yes` or interactive approval; without either it exits `3`. A policy refusal at exit `2` has JSON `ok:false` with `reason: "policy.perTask"` or `reason: "policy.perDay"`. Invalid usage exits `1` with `{ok:false,error:{code:"usage_error",message}}`. Run `vapi task --help` for details. Chain operations require a locally trusted escrow factory. Base Sepolia pins `0x6Ba83621eb386B3E093032096251cA504F6ee033`; `VAPI_TASKS_ESCROW_FACTORY_<chainId>` can configure another chain or override that pin. Base Sepolia uses `BASE_SEPOLIA_RPC_URL`, or `https://sepolia.base.org` when the variable is unset. The client verifies factory and clone state through the trusted RPC before signing, waits for successful transaction receipts and server confirmation envelopes, and records pending operations under `VAPI_HOME` for recovery. Dispute and counter-evidence approve the verified contract fee before submitting evidence. Local per-task, daily and approval policies apply to that fee. Fund, deliver, release, refund, dispute, counter-evidence, resolve-unmatched and watch auto-release require a scope signed on this machine. `--counterparty` only confirms the existing local binding. See [task security and recovery](./tasks.md).

Posting a task moves no money. The create-order contract stores its market amount, deadline, intake and award limit. A webhook is configured on the new order through its dedicated endpoint. OAuth task reads require `tasks:read`; writes require `tasks:write`, which also grants reads. See [Task commands](./tasks.md#cli).

Every Railway destroy requires exit zero, including launch-failure, signal, persistence-rollback, terminal-status and direct-stop cleanup, even when failure text says “not found.” Stderr warnings on exit zero are harmless. Failed launch cleanup retains an identified orphaned sidecar; failed terminal-status cleanup stays `running` and retries on refresh. A failed starting or running stop becomes `unknown` and keeps blocking dissolution. Verify destruction in the original Railway project/environment, then use `vapi swarm forget-run <name> <runId> --confirm-destroyed` if a successful destroy is unavailable.

Sent ETH by mistake? The wallet keeps the ETH you sent on Base. Send it back minus the Base network fee; a tiny amount may stay behind.

```sh
vapi sweep <your-address> --asset eth
```

Phrase recovery checks Base USDC balances until five consecutive addresses are empty and reports the number scanned. `vapi restore --accounts <n>` (or `vapi setup --accounts <n>` when restoring) derives a fixed count without balance queries.
